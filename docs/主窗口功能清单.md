# 主窗口功能清单

> 当前 project-group 插件主界面的**实际**功能。
> 标注 `[原版有·当前缺]` 的见文末对照。

---

## 一、整体布局

```
┌──────────────────────────────────────────────────────────┐
│ 工具栏：＋新建项目 / ＋新建项目组 / 发送到AI / 刷新 /      │
│         清除无效项 / 设置在哪？                            │
├────┬─────────────────────────────────────────────────────┤
│ 左 │  项目栏      │  项目组栏     │  内容浏览              │
│ 操 │  （页签切换） │ （分类堆叠）  │  agent/skill/rule     │
│ 作 │              │              │                        │
│ 栏 ├──────────────┴──────────────┴────────────────────────┤
│    │  日志区（复制全部 / 清空 / 右键复制该条）             │
└────┴─────────────────────────────────────────────────────┘
```

- **左操作栏**：图标在上、文字在下，固定 72px
- **项目组栏**：纵向堆叠，所有分类同时可见、各自可折叠（对照截图 创作/游戏设计/财务/政策 一次看全）
- **项目栏**：页签切换（与原版一致）
- **日志区**：显示最近 40 条（存 200），错误标红

---

## 二、左操作栏

分组沿用原版：全局 → 选中项 → 连锁动作 → 危险操作（红色置底）。
**每项下方显示键位**（`mod` 按平台自动显示 ⌘ 或 Ctrl）。

| 组 | 项 | 键位 |
|---|---|---|
| 全局 | 刷新 / 备份 / 清无效 | F5 / — / F8 |
| 选中项 | 打开 / 保护 / 改名 / 搬家 / 改色 / 改图标 | mod+O / mod+L / F2 / — / F4 / F6 |
| 危险 | 移除 | Del |
| 连锁 | 自定义动作（勾选"加入右键菜单"的也列在卡片右键） | 可自定义 |

---

## 三、卡片

| 元素 | 说明 |
|---|---|
| 图标 | 自定义图标或默认字形 |
| 标签色 | 左侧色条 + 圆点；hover/press 有派生色；圆点按明暗加对比边框 |
| `🔗 N` | 链接数 |
| `→ 项目组名` | **点击可跳过去定位**（仅项目卡片） |
| 徽标 | 冲突 / 失效 / 锁 / 继承 |
| 缺失 | **红框**（优先级高于 hover），一眼可辨 |

**右键菜单**：打开 / 复制完整路径 / 改名 / 保护（ACL）/ 图标与标签 / 发送到 AI / 撤销链接 / 移除 / 搬家

---

## 四、拖放

| 操作 | 语义 |
|---|---|
| 项目 → 项目组卡片 | **建链**（弹选择框，可选链接名） |
| 跨栏拖到**空白** | **换栏移动**（项目⇄项目组，可带物理搬家） |
| 同栏卡片互拖 | 排序 |
| 卡片 → 页签 | 移动到该页签 |
| 页签 → 页签 | **重排页签顺序** |

---

## 五、内容浏览（右栏）

| 项 | 说明 |
|---|---|
| 类别筛选 | 全部 / Agent / Skill / Rule（带计数） |
| 目录直达 | 打开目录 / **Agent 目录 / Skill 目录 / Rule 目录** |
| 刷新 | 重新扫描 |
| 预览 | 只读；目录型 skill 自动读其下 SKILL.md |
| 条目操作 | 所在目录 / 外部编辑 / 改名 / 复制名 / 复制路径 / **复制文件名** |

---

## 六、快捷键

| 键位 | 功能 |
|---|---|
| `mod+O` / `mod+L` | 打开 / 保护 |
| `F2` / `F3` / `F4` / `F6` | 改名 / 换栏 / 改色 / 改图标 |
| `Del` | 移除 |
| `mod+Tab` / `+Shift+Tab` | 翻项目组分类 |
| `mod+PageDown/PageUp` | 翻项目页签 |
| `mod+←/→` | 切换键盘焦点栏（栏标题显示 ⌨） |
| `F5` / `F8` | 刷新 / 清除无效项 |

**两条让路规则**：焦点在 input/textarea/select 里不触发（否则改名框里按 Delete 会删卡片）；有弹窗时整组不触发。
