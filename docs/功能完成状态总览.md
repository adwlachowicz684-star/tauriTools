### MCP · S1 别名层 ✅（此前文档标为待办）

`mcp.rs` 已实现 `ALIASES` 表：

```
backup_now → backup          lock_set  → set_lock
list_agents → scan_content (补 kind=agent)
list_skills → scan_content (补 kind=skill)
create_project / create_group → create_folder
```

设计要点（注释里写了）：**只在 `tools/call` 接受，不进 `tools/list`**，
且**必须在查开关之前**归一化——否则用户关掉 `backup` 后用 `backup_now` 还能调，是个绕过口子。
