### MCP · S1 别名层 ✅（此前文档标为待办）

`mcp.rs` 已实现 `ALIASES` 表（**9 条**）：

```
backup_now → backup                lock_set  → set_lock
list_agents → scan_content (补 kind=agent)
list_skills → scan_content (补 kind=skill)
list_rules  → scan_content (补 kind=rule)   ← 三件必须成套
refresh_content → scan_content     create_project / create_group → create_folder
folder_icon_set_dll → folder_icon_set
```

设计要点（注释里写了）：**只在 `tools/call` 接受，不进 `tools/list`**，
且**必须在查开关之前**归一化——否则用户关掉 `backup` 后用 `backup_now` 还能调，是个绕过口子。
补默认参数（`kind`）同样关键：只改名不补参 = 旧调用返回 all，语义错误但不报错。
