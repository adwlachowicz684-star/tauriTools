```csharp
private string UniqueIconName(string baseName) {
    var name = baseName; var n = 1;
    while (File.Exists(FullPath(name)) || allNames.Contains(name, OrdinalIgnoreCase))
        name = $"{baseName}({++n})";
    return name;
}
```

## 二、连锁动作页签

### 2.1 内置动作**不让位**（固定墙）—— ✅ 已补（本轮）

```csharp
// SettingsPanel.xaml.cs:760
/// 内置页签视为固定墙不可借位

// 右邻：自定义才可让位 / 左邻：自定义才可让位
```

当前 #148/#149 用的是通用 `gapIndexAt`，不区分内置/自定义，
于是**自定义动作可以拖到内置动作位置去交换** —— 而后端
`ensure_actions` 是按固定顺序重建内置的，拖完看着变了、刷新又回去。

### 2.2 换位**死区 14px** —— ✅ 已补（本轮）


当前用 `gapIndexAt`（越过中心即换位），**没有死区**。
这与 #75 是同一类问题（内核有 `swapIndexWithDeadZone`、但没接到这里）——
**第二次踩到"内核写了却没接入"**。

### 2.3 页签条**滚轮横向滚动** —— 不适用，撤掉

复核：本项目连锁动作是**纵向列表**（`.fpx-ca-list` 宽 190、`overflow:auto`），
没有横向溢出；原版 `acTabs` 是横向页签条才有这个需求。
抄过来会是一个永远不会被触发的功能。

```csharp

    if (sv == null || sv.ScrollableWidth <= 0) return;
```

动作多了横向溢出后，只能靠拖滚动条。

## 四、外部拖入（#14，待宿主）

原版 `MainWindow.xaml.cs:1813` 起的真实语义（比清单描述更完整）：

| 行为 | 原版 |
|---|---|
| 落点 | 项目卡片流 → 活动页签；项目组区 → **按指针算出具体分框**（`GroupBoxIndexAt`） |
| 页签 | 拖到页签 → 加入**那一个**页签；悬停时**实时切换**页签 |
| 过滤 | `Directory.Exists(p)` —— **只收目录**，文件一律丢 |
| 多个 | `foreach` 全部加入，不是只取第一个 |
| 效果 | `DragDropEffects.Copy`；非 FileDrop 给 `None`（明确拒绝） |

当前版本因为沙箱拿不到绝对路径，做的是"打开选目录对话框 + 带名字"。
等宿主拖放能力就绪后按上表重做。

## 五、已比对确认**对齐**的部分（不用再动）
