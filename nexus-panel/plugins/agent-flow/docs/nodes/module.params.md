## 面板上的提示

> 模块的内部结构在右侧「编辑内部」里改。改模块库会让所有实例跟着变；改这个实例会让它脱钩成独立副本。

这个控件没有可调参数（结构由画布上的连线决定）。

## 怎么用它

1. 从侧栏「工具」分组拖到画布
2. 在属性面板填参数（面板由 `nodes/defs/module.ts` 的 fields 自动渲染）
3. 用连线接到上下游；引用上游输出写 `{{上游id.output}}`

## 建节点的正确方式

用 `def.create()`（即 `makeXxxNode`）建节点，它会填好默认值。
手工拼 `{ kind: 'module' }` 会缺默认字段 ——
本控件没有隐藏字段，但用 create() 仍是推荐做法。
