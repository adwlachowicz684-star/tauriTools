## 怎么用它

1. 从侧栏「任务」分组拖到画布
2. 在属性面板填参数（面板由 `nodes/defs/task.tsx` 的 fields 自动渲染）
3. 用连线接到上下游；引用上游输出写 `{{上游id.output}}`

产出是文本，可以：
- 直接给下游用（`{{task节点id.output}}`）
- 接「condition」节点做判断

## 建节点的正确方式

用 `def.create()`（即 `makeXxxNode`）建节点，它会填好默认值。
手工拼 `{ kind: 'task' }` 会缺默认字段 ——
本控件没有隐藏字段，但用 create() 仍是推荐做法。
