## 怎么用它

1. 从侧栏「控制器」分组拖到画布
2. 在属性面板填参数（面板由 `nodes/defs/timeout.tsx` 的 fields 自动渲染）
3. 用连线接到上下游；引用上游输出写 `{{上游id.output}}`

## 建节点的正确方式

用 `def.create()`（即 `makeXxxNode`）建节点，它会填好默认值。
手工拼 `{ kind: 'timeout' }` 会缺默认字段 ——
本控件没有隐藏字段，但用 create() 仍是推荐做法。
